# Feature guide

| Feature | Where | Who needs it | How to set it up |
| --- | --- | --- | --- |
| First Steps checklist | Dashboard | Every new company | Appears automatically after sign-up: business type, calendar, calls/texts/email, team, test run. Each step can be skipped; it never blocks the dashboard. |
| Industry quick-starts | Applied from the business type | All 28 supported business types | Chosen in First Steps; sets recommended agents, connections and wording. |
| Scheduling & calendar | `/dashboard/appointments` | Anyone who books work | Connect a calendar, set business hours and services. |
| Leads & follow-up | `/dashboard/leads` | Anyone quoting work | Nothing to set up; add follow-up agents to chase automatically. |
| Quotes & invoices | `/dashboard/quotes`, `/dashboard/invoices` | Trades, repair, outdoor, fencing, roofing, solar, pool | Connect payments to take cards. |
| Dispatch & field work | Operations | Companies with crews | Add employees, set job types and availability. |
| AI receptionist (English & Spanish) | Agent hub | Anyone missing calls | Connect calls/texts, then optionally AI voice. |
| Agent hub | `/dashboard/agents` | Everyone | Switch on job types, pick ready-made wording. |
| Analytics | `/dashboard/analytics` | Owners and managers | Nothing to set up; tabs for overview, revenue, customers, forecast, performance. |
| Connections + Health | `/dashboard/integrations` | Everyone | One page per provider, plus a Health tab showing reliability. |
| Marketing & campaigns | `/dashboard/campaigns` | Companies chasing repeat work | Email needs a verified sending domain. |
| Social posting | Marketing | Optional for everyone | Upload-Post for automatic posting, or manual Copy & Post on any plan. |
| Customer portal | `/customer-portal` | Booking and home-health businesses | Enabled with the plan; customers self-serve bookings and invoices. |
| Product tour | Help menu | New users | Runs after First Steps; replayable any time. |

Walkthrough videos: none recorded yet. The empty-state guides and tour accept a video link (`videoUrl`), so they can be dropped in without code changes once the recordings exist.
